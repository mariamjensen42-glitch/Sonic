# 音乐库

## 扫描

Sonic 通过 **MediaStore** 扫描本机音频，不自己遍历文件系统：

- 判定：MIME 类型 + 文件后缀双重判定，覆盖 MP3 / FLAC / OGG / MP4 / WAV / AIFF / WMA / DSF / DFF / Opus / AAC
- **排除录音**（默认开启）：按路径目录名 + 标签识别通话录音、闹钟、播客并跳过，可在设置里关
- **排除目录**：设置里可自定义要跳过的文件夹

## 分类浏览

音乐库页按四个分区组织：

| 分区 | 内容 |
| --- | --- |
| 歌曲 | 全部音频，按标题 / 艺人 / 专辑 / 时长排序 |
| 专辑 | 按专辑聚合，点进去是专辑详情页 |
| 歌手 | 按艺人聚合，点进去是歌手详情页 |
| 歌单 | 用户自建 + 导入 |

## 歌单

- 自建歌单、新建歌单
- 歌单详情页复用专辑 / 歌手详情页那套版式
- **导入 QQ 音乐歌单**：音乐库 → 右上角「＋」→「导入歌单」，粘贴 QQ 音乐歌单分享链接即可拉取

## 收藏与「我喜欢」

「我喜欢」页改成歌单详情那套版式 —— 不再是 Apple 的满铺方形 hero，
而是标题压在做旧封面上、下面跟列表，跟歌单保持一致。

## 搜索

搜索页分两段：

- **本地**：按歌名 / 艺人 / 专辑匹配
- **在线**：走[在线音源](online-sources.md)的目录搜索

在线结果上方有一条**平台切换 tab**：全部平台 / 网易云音乐 / QQ 音乐 / 酷狗音乐 / 酷我 / 咪咕，
点一条直接播。

## 元数据编辑

歌曲详情页支持全字段元数据编辑与封面管理：

- 标题 / 艺人 / 专辑 / 年份 / 流派 / 音轨号 / 碟片号等
- 封面：换图后立即生效（不会再出现「换完还是上一张」—— 缓存 key 带图片哈希）
- 标签读写统一走 **jaudiotagger**：MP3 / FLAC / OGG / MP4 / WAV / AIFF / WMA / DSF 全格式读写，DFF 只读；
  Opus 与裸 AAC 退到 `MediaMetadataRetriever` 拿基础字段

## 统计

播放次数、最近播放、听歌时长等统计在[均衡器与统计](tools.md)页有说明。
