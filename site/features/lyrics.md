# 歌词

## 支持格式

Sonic 在 `domain/lyrics/parser/` 里实现了一套 `ILyricsParser` 接口，覆盖主流歌词格式：

| 格式 | 说明 |
| --- | --- |
| **LRC** | 标准逐行歌词 |
| **增强 LRC** | 带词级时间戳（`<mm:ss.xx>`） |
| **TTML** | Timed Text Markup Language，AMLL 官方 TTML API 返回的就是它 |
| **逐字歌词** | 逐字（音节）级时间轴，Lyricify Syllable 风格 |
| **逐词 LRC** | 词级同步 |

## 卡拉 OK 效果

- 当前行**逐字高亮**，非当前行自动淡出
- 聚焦行放大（`1.04`），非聚焦行缩小（`0.92`），视觉焦点明确
- 首尾两端 24dp **渐隐**，歌词不会顶到屏幕边缘
- 点击歌词行**跳转到对应时间点**
- 支持**译文**开关：顶栏一颗翻译按钮，译文单独一行显示
- 字号 / 居中对齐 / 辉光 / 模糊都可在设置里调

## 在线歌词

顶栏的歌词按钮可以一键进入**在线歌词版本选择**，不用再套一层菜单。

支持的在线来源：

| 来源 | 说明 |
| --- | --- |
| AMLL | 官方 TTML HTTP API，逐词歌词质量最好。按曲名变体多轮检索（先去掉 `(Live)` 之类噪音，再退回标签原文），多份候选依次下载，缺歌手标签时用平台 id / 同专辑 / 曲名唯一性作旁证 |
| 网易云音乐 | 逐词歌词 |
| QQ 音乐 | 逐词歌词，含非标准 **QRC** 格式（由 `QrcCodec` 解码） |
| 酷狗音乐 | 歌词 + 翻译 |
| LRCLIB | 开源歌词库 |
| 音源脚本 | 洛雪脚本里声明的 `lyric` action |

!!! tip "QQ 的 QRC"
    QQ 音乐的 QRC 不是标准 LRC，用的是自有的压缩编码。
    `QrcCodec` 按 AMLL 的 `formats/eqrc` 1:1 移植解码，能拿到逐字时间轴。

## 歌词的存放位置

- 本地歌词：随歌曲存在同名 `.lrc` / `.ttml` 文件里
- 数据库歌词：在线抓取后存进 Room（`LyricsRepositoryImpl`），带清除路径
- 导出：`domain/lyrics/exporter/` 支持把歌词导出成标准 LRC 文件
