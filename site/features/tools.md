# 均衡器与统计

## 均衡器

内置音频均衡器，作用于播放链路：

- 多段频段调节
- 预设切换
- 增益曲线在设置页可视化

## 听歌统计

| 指标 | 说明 |
| --- | --- |
| 播放次数 | 播放超过 **50%** 才计入，避免误触被算成听完 |
| 听歌时长 | 累计有效播放时长 |
| 最近播放 | 按时间倒序 |
| 最常播放 | 按次数倒序 |
| 高解析（HR）/ 无损（SQ） | 按容器 + 码率统计，阈值与播放页音质标识同源 |

统计页在应用内的「统计」入口。

## 桌面小部件

支持桌面小部件（`presentation/widget/`）：

- 播放 / 暂停控制
- 当前曲目信息
- 状态栏歌词

小部件图标使用从 Flamingo 抽取的同款 XML 矢量资源。

## 排行榜

应用内提供排行榜（`presentation/leaderboard/`），按统计维度给出排行。
