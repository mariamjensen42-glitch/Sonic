# 播放与队列

## 播放内核

Sonic 用 **Media3 ExoPlayer 1.9.0** 做播放内核，`PlayerManager` 封装成单例，
`PlayerService`（`MediaSessionService`）负责前台服务保活与通知栏控制。

| 能力 | 说明 |
| --- | --- |
| 后台播放 | `MediaSessionService` 前台服务，退到后台 / 息屏继续播 |
| 通知栏控制 | 上一首 / 播放暂停 / 下一首 + 进度条拖动 |
| 媒体会话 | 通知栏 / 锁屏 / 蓝牙耳机 / 车机都能接管 |
| 队列管理 | 添加、删除、拖拽排序、跳转 |
| 变速 | 0.5× ~ 2.0×，滑杆 + 5 档快捷芯片 |
| 定时关闭 | 到点自动暂停 |
| 淡入淡出 | 切歌交叉渐变，时长可配 |
| 智能续播 | 播完自动接下一首，跨会话偏好 |

## 播放页

播放页是一个**浮层**，盖在当前页面之上，而不是独立路由 —— 下拉可以整页跟手收回。

结构上分三页横向滑动：

1. **封面页** —— 满宽大图 + 标题 + 控制区
2. **歌词页** —— 卡拉 OK 歌词
3. **队列页** —— 播放队列

封面在迷你播放条与播放页之间**共享**（`PlayerArtworkTransition`），
从底部迷你条点开时封面是同一张图连续放大过去的，不是两张图切换。

## 播放设置面板

点播放页顶栏的「播放设置」弹出底部面板，里面直接调：

- 倍速滑杆 + 5 档快捷芯片
- 定时关闭
- 频谱条开关（播放页底部那排跳动的柱条）
- 自动续播 / 淡入淡出

## 队列页的四档模式

队列页顶部是四颗等宽胶囊：

| 胶囊 | 作用 |
| --- | --- |
| 随机 | 随机播放 |
| 循环 | 列表循环 |
| ∞ 智能续播 | 播完自动接下一首 |
| ◉ 淡入淡出 | 切歌交叉渐变 |

选中那档反白（白 70% 底 + 黑图标），未选中是白 12% 半透明底，整排压在封面色面上。
后两档直接写设置项（`autoContinueEnabled` / `audioFadeDurationMs`），是跨会话偏好。

## 音质标识

播放页进度条下方中间位显示当前曲目的音质：

- 无损容器（flac / wav / aiff / ape / wv / tta / dsf）且码率 ≤ CD → 显示「无损」
- 无损容器且码率 > 1411 kbps → 显示「Hi-Res 无损」
- 有损格式 → 该位置留白

!!! note "为什么有损不显示"
    Apple Music 在这一格对有损曲目也是留白的。
    硬塞一个「MP3 320k」只会让这一行变吵。

判定按「容器 + 码率」两级，与设置页统计 SQL（HR / SQ）用的是同一套阈值。

## 播放统计

歌曲播放超过 **50%** 才计入播放次数，避免误触被算成听完。
统计结果在[均衡器与统计](tools.md)页有说明。
