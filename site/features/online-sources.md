# 在线音源

Sonic 内置了**洛雪协议（LX）**音源脚本引擎，可以在不装第二个 App 的前提下播在线歌曲。

## 内置音源

应用包内自带三套洛雪音源（`assets/lx_sources/`）：

| 音源 | 支持 |
| --- | --- |
| 星海音乐源 | wy / tx / kg / kw / mg 五个平台，含取词与封面 |
| 酷狗音乐源 | kg |
| 聚合音乐源 | 多平台聚合 |

也可以自己导入音源脚本。

## 洛雪脚本引擎

| 模块 | 职责 |
| --- | --- |
| `online/lx/LxJsRuntime` | QuickJS 运行时，脚本沙箱 |
| `online/lx/LxScriptRunner` | 脚本生命周期管理 |
| `online/lx/LxHttpBridge` | 宿主 HTTP 桥 |
| `online/lx/LxJsUtils` | 宿主工具函数桥 |
| `online/lx/LxPluginManager` | 插件导入 / 排序 / 屏蔽 / 取链 / 取词 / 取封面 |
| `online/lx/QrcCodec` | QQ 音乐 QRC 逐字歌词解码 |

脚本能声明三个 action：

| action | 作用 |
| --- | --- |
| `musicUrl` | 取播放链接 |
| `lyric` | 取歌词 |
| `pic` | 取封面 |

!!! tip "三个 action 都接上了"
    早期版本只实现了 `musicUrl`，脚本里声明的取词、取封面拿不到。
    现在三个都通，导入一个完整音源就能连词带图一起用。

## 插件健康度

连续取链失败 **2 次**的插件会被排到队尾；成功一次立刻恢复正常排序。
降权只是稳定排序用的，不封禁插件 —— 平台抽风是常态，硬封会把能用的脚本一起废掉。

## 取链与可播性探测

取链统一走 `online/CachedPlaySourceResolver`：

1. 先查 `play_url_cache` 表
2. 没有再跑脚本取链

取到的 URL 会交给 `PlayUrlProbe` 探测是否真的能播 —— 很多音源返回的是 200 但内容是 404 页面，
不探测就会出现「搜到歌了但一首也播不了」。

| 网易云音乐 | ✔ |

## 元数据刮削

设置 → 在线音乐 → 元数据刮削：把**元数据不全**的本地歌曲用在线目录补齐。

匹配逻辑在 `domain/scrape/ScrapeMatch` 里，是纯函数：

- 归一化标题（去括号、去修饰词）
- 置信度打分
- 缺失字段判定

「全部刮削」只应用**可信匹配**；点某一行会展开候选列表手动挑。

## 导入与排序

- 导入脚本：设置 → 在线音源 → 导入
- 排序 / 屏蔽：插件列表里拖拽排序，或把某个插件屏蔽掉
