Migrate Pattern C screens (FolderScreen, AiInfoScreen) from `Column` + inline TopAppBar to `M3Scaffold`.

**Changes to `AiInfoScreen.kt`:**

   - Remove `import androidx.compose.foundation.layout.Column` (line 6) — ONLY IF `Column` is no longer used. Check: `Column` is used at line 62 (error state) and line 72 (content state). **Keep this import.**

3. **Structural rewrite of the outer layout (lines 50-78):**

Replace:
```kotlin
    Column(Modifier.fillMaxSize().background(SpotifyColors.Background).statusBarsPadding()) {
        M3DetailTopAppBar(
            title = "AI 解读",
            navigationIcon = Icons.AutoMirrored.Filled.ArrowBack,
            navigationIconContentDescription = "返回",
            onNavigationClick = onNavigateBack
        )

        Box(Modifier.fillMaxSize().padding(16.dp)) {
            when {
                uiState.isLoading -> ...
                uiState.error != null -> ...
                else -> ...
            }
        }
    }
```

With:
```kotlin
    M3Scaffold(
        topBar = {
            M3DetailTopAppBar(
                title = "AI 解读",
                navigationIcon = Icons.AutoMirrored.Filled.ArrowBack,
                navigationIconContentDescription = "返回",
                onNavigationClick = onNavigateBack
            )
        }
    ) { paddingValues ->
        Box(Modifier.fillMaxSize().padding(paddingValues).padding(16.dp)) {
            when {
                uiState.isLoading -> Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) { M3CircularProgressIndicator() }
                uiState.error != null -> {
                    Column(Modifier.fillMaxSize(), horizontalAlignment = Alignment.CenterHorizontally, verticalArrangement = androidx.compose.foundation.layout.Arrangement.Center) {
                        Text(uiState.error ?: "", color = SpotifyColors.TextSecondary, fontSize = 15.sp)
                        Spacer(Modifier.height(16.dp))
                        if (uiState.error == "需要配置 API Key") {
                            Button(onClick = onNavigateToApiKeyConfig) { Text("前往配置") }
                        } else {
                            Button(onClick = { viewModel.handleIntent(AiInfoIntent.Retry) }) { Text("重试") }
                        }
                    }
                }
                else -> Column(Modifier.verticalScroll(rememberScrollState())) {
                    Text(name, color = SpotifyColors.TextPrimary, fontSize = 20.sp, fontWeight = FontWeight.Bold)
                    Text(uiState.content, color = SpotifyColors.TextSecondary, fontSize = 14.sp)
                }
            }
        }
    }
```

**Key changes:**
- `.background(SpotifyColors.Background)` removed — M3Scaffold provides it
- **CRITICAL: `.statusBarsPadding()` removed** — Scaffold handles insets natively. Keeping it would cause double-padding (content shifted down twice).
- `M3DetailTopAppBar` moves to `topBar = { ... }` slot
- Content box uses BOTH `paddingValues` (from Scaffold, for TopAppBar/inset spacing) AND the existing `.padding(16.dp)` (for content margin). The order matters: `paddingValues` first (for system insets), then `16.dp` (for content spacing). Use chaining: `.padding(paddingValues).padding(16.dp)`.
- Inner content (`when` block) is **unchanged** except for wrapping indentation.

4. **Verify imports after changes:**

   - `import androidx.compose.foundation.layout.Column` — **keep** (used in error/compos state 内)
   - `import androidx.compose.material3.ExperimentalMaterial3Api` — **remove**
   - `import com.cycling.sonic.core.ui.components.M3Scaffold` — **add**

DO NOT change the internal content logic of loading/error/success states.
DO NOT remove `.padding(16.dp)` — that's intentional content margin.
DO NOT remove the `Column` import — it's still used inside the error and content branches.
